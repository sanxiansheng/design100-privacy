开始使用

  1. 在 Mac 上打开 design100。
  2. 在 Figma 设计文件中运行配套 design100 插件。插件是必需的；如果找不到安装入口，请通过下方邮箱联系开发者获取安装帮助。
  3. 复制 Mac 应用的配对码，粘贴到插件并连接，保持应用和插件同时运行。
  4. 在 Figma 中选择画板或图层，在 Mac 应用中查看预览。
  5. 使用左侧按钮导出前端包、组件或验收 Skill。下载由插件完成。
  6. 将复制的还原提示词与对应导出文件一起提供给你使用的 AI 编程工具。

常见问题

无法连接：确认应用和插件在同一台 Mac 上运行。系统询问本地网络权限时，允许 Figma 访问本地网络，然后重试连接。更换配对对象后重新复制配对码连接。

没有预览：先选择 Figma 画板或图层，并等待加载完成。复杂设计可能需要更多时间，可以先选择较小区域检查。

没有下载：检查 Figma 插件的状态和下载提示，以及系统或浏览器的下载目录。连接中断后，请重新连接再导出。

如何复用已有组件：将设计包和提示词提供给可以访问项目代码的 AI 工具，要求其先检查已有组件再实现。design100 本身不读取项目源码，也不直接调用 AI。

Getting started

  1. Open design100 on a Mac running macOS 14 or later.
  2. Run the companion design100 plugin in your Figma file. The plugin is required. Contact us below if you need help finding its installation entry.
  3. Copy the pairing code from the Mac app into the plugin and connect. Keep both running on the same Mac.
  4. Select a frame or layers in Figma to see a preview.
  5. Use the sidebar to export design packages, components or verification materials. The plugin handles downloads.
  6. Give the copied restoration prompt and exported files to your AI coding tool.

Troubleshooting

Connection: Keep both app and plugin running on the same Mac. Allow Figma local network access if prompted, then retry. Pair again if you change the paired app or plugin.

Preview: Select a frame or layers and wait for loading. Try a smaller selection for complex designs.

Downloads: Check plugin messages, download prompts and your Downloads folder. Reconnect before retrying if disconnected.

Component reuse: Give your exported files to an AI tool with access to your project and ask it to inspect existing components. design100 does not inspect your source code or call an AI service.
